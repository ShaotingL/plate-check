# 車牌名單比對（PWA）

用手機鏡頭即時辨識車牌，比對使用者自己匯入的名單。辨識在手機上進行，名單只存在使用者的手機。

## 資料夾內容

| 路徑 | 說明 |
|---|---|
| 根目錄 | 整個網站（GitHub Pages 直接從根目錄發布） |
| `index.html` | 主程式（介面、比對、同步，含繁體中文註解） |
| `sw.js` | Service Worker：離線快取＋啟用多執行緒 |
| `models/`、`lib/` | 車牌偵測／辨識模型與 ONNX Runtime Web |
| `licenses/NOTICE.txt` | 第三方元件的授權條款全文（散布時必須保留） |
| `serve.py` | 本機測試用伺服器：`python -m http.server` 後開 `http://localhost:9123` |
| `docs/apps_script.gs` | 選用：Google 試算表同步用的 Apps Script |

## 上線（擇一）

需要 https 網址，相機才能使用。約 31 MB，都是靜態檔案。

- **GitHub Pages**：建立 repository，把 `` 內的檔案放到根目錄，Settings → Pages → 選擇分支。
- **Cloudflare Pages / Netlify**：把 `` 資料夾整個拖進去部署。

上線後把網址給使用者：手機開網址 →「加到主畫面」→ 之後像一般 app 一樣點圖示開啟，第一次載入後可離線使用。

## 使用者怎麼用

1. 開啟後按「匯入名單」：從試算表複製儲存格貼上，或選 CSV 檔。
   每列要有一個車牌（如 `ABC-1234`），同列其他欄位會在比對到時顯示（電話、姓名、車位都可以）。
2. 按「開始掃描」，允許相機。
3. 用完到「設定」按「清除名單和紀錄」。

## Google 試算表同步（選用，每位使用者用自己的試算表）

1. 開一份新的 Google 試算表 → 擴充功能 → Apps Script，貼上 `docs/apps_script.gs`。
2. **把 `TOKEN` 改成自己的密碼**（沒改會拒絕所有連線）。
3. 部署 → 新增部署作業 → 網頁應用程式；執行身分「我」、存取權「所有人」。
4. 在 app「設定 → Google 試算表同步」貼上網址和密碼。
5. 在「名單」工作表填 A 欄車牌、B 欄顯示內容，app 就能「從 Google 試算表載入」。

## 更新版本

改完檔案後，把 `sw.js` 裡的 `CACHE = "plate-app-v18"` 改成新版本號，使用者下次開啟會自動更新。
新增或刪除檔案時，同步修改 `sw.js` 的 `FILES` 清單。

## 已知限制

- 辨識準確度會受光線、角度、距離、車牌髒污影響；重要用途請目視確認。
- 「唸出車牌」使用手機內建語音，手機需安裝中文語音。
- iPhone 上尚未實機測試（需從 Safari「加入主畫面」）。
- 車牌與名單內容屬於個人資料，使用者須自行確認有權使用該名單。
